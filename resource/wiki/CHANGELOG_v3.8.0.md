# Fntv-Plus 更新日志

## v3.8.0 (2026-10-04)

> 本次更新**上线飞牛 fnOS 应用（fpk 版）**，并集中优化登录逻辑、弹幕体验与刮削：访问码登录与证书信任重构、弹幕样式持久化保存、自建弹幕拉取全面优化、新增 Jav 番号刮削；另有一批小功能与修复一并上线。

### 🎉 飞牛 fpk 应用上线
- **飞牛影视增强以 fnOS 微应用形式上架**：NAS 装一次，电视 / 平板 / 手机 / 电脑浏览器打开影视即是增强版，不改飞牛系统与影视应用任何文件，卸载即还原。
- **移动端适配**：手机 / 平板 / 电视浏览器全响应式（季页 / 详情页 / 轮播 / 设置 / 观影记录 / 每日放送）。
- **应用内一键打包（GUI）**、安装许可中文化、卸载可选清空全部数据目录（修复卸载重装后设置 / 凭证 / 弹幕缓存「数据全都在」）。
- 桌面端与 fpk 两端功能同步迭代，体验一致。

### 🔐 登录逻辑优化
- **访问码登录**：登录页新增可选「访问码」字段，输一次码即可建立会话并自动记忆，之后免重输；FN ID OAuth 窗口遇门禁页自动填码；访问码加密存储、启动自动重验证（桌面端与 fpk 两端生效）。
- **修复「一直弹证书不信任」死循环**：信任列表写的是配置里的原始 server，真正 TLS 握手失败的是 80 端口重定向后的 https 真实端口；现在按真实握手主机入信任列表，Node / MPV / 兜底三端同步，私有地址免验证对齐。
- **修复 fpk 门禁两连**：访问码登录后变原始网页（登录链 302 跳出网关命名空间）、门禁解锁 Cookie 按回环 Host 校验导致的无限循环。

### ✨ 弹幕样式持久化保存
- **MPV 弹幕样式菜单改动自动保存**：合并回写 uosc_danmaku.conf（字段级合并，密文凭证与开关不受影响），重启 / 重开不再丢；屏蔽词保存独立成键，不再冲掉样式设置。
- **弹幕样式默认值修正**：字号 / 透明度 / 描边对齐设置面板默认，显式指定中文字体，根治「弹幕很糊、字体怪」。
- **弹幕字号自适应**：4K / 高 DPI / 超宽屏自动补偿，描边阴影随字号同比缩放，显示环境变化自动重建。

### 🚀 自建弹幕拉取优化
- **系列匹配记忆**：以季为键记住命中条目，各集标题元数据不一致（中文名 / 日文名混排）也能整季稳定命中，不再「第一集能中第二集搜不到」。
- **低阈值聚合**：自建源命中但弹幕低于阈值时自动叠加内置 B站弹幕（条目级合并去重），个位数弹幕的条目不再终结整条链路。
- **弹弹play 省配额**：跨会话条数闸门 + 同集会话内去重，开放 API 不再被无谓重拉；日文原名自动换中文名重试。
- **弹弹play 兜底接入桌面端网页播放器**（fpk 版此前已支持，本次桌面端补齐、双端一致）：自建源与 B站 都未命中时自动降级弹弹play（设置里填的自定义凭证优先，内置凭证按需使用），手动搜索可直接选弹弹play 条目，「来源详情」逐源展示三源状态。
- **手动搜索增强**：MPV 搜索接自建源候选置顶直选；网页端手动搜索支持 B站正版条目选定（按季锁定逐集对位）、番剧区 / 视频区候选合并展示并亮官方弹幕数，新增「清除弹幕」按剧重置错误匹配。
- **B站 Cookie 每日体检**：登录态过期不再静默失败，来源详情面板常显体检结论；扫码登录 / 手动粘贴后状态即时刷新，无需重启。
- **已完结番剧弹幕源锁定**：手动选定或自动命中后整季复用，每集按集号精确取分 P。

### 🎬 Jav 番号刮削
- 电影详情页出现「⟳ jav 刮削」按钮，按番号自动查询回填标题 / 简介 / 日期 / 封面（锁定防覆盖已有内容），封面就地替换。
- 支持文件夹模式：夹名无番号自动递归子文件，夹与子视频双重回填；演员真实落库（搜索 / 建人 / 头像）。
- 修复「显示失败但数据实际已写入」的回填判定。

### 🧩 其他功能更新
- **Fntv-Plus 功能列表大补齐（对照 mpv-Yaozhi 杳知菜单）**：一次性引入 21 个原样捆绑的社区/官方脚本（全部纯 Lua、标准 mpv API、无外部依赖，许可与来源见 `scripts/THIRD-PARTY-LICENSES.md`），功能列表从 11 项扩到 24 项 —— 新增：**PGS 字幕亮度**（自动识别/跟随视频峰值/150–400 nits 五档预设）、**章节跳过**（按章节名跳 OP/ED/广告，none/auto/manual 切换 + F3 跳到静音点）、**按住右方向键平滑快进**（evafast，可开关）、**动态去黑边**、**画中画**、**截屏**（原样/框选裁剪/双图拼接）、**导出当前字幕**、**快捷键绑定列表**（uosc 内中文搜索/修改/恢复）、**最近播放**、**字幕自动对轴**、**字幕搜索下载（ASSRT，脚本此前已捆绑本次接入菜单）**、**字幕行列表跳转**；另含九个自动生效项：运行时属性跨会话记忆（音量/倍速/字幕延迟）、跳转反馈动效、本地同目录自动连播（带扩展名黑名单）、播放状态定时自动保存、音轨/字幕智能选择（非配音优先）、跳转撤销重做、挂载盘下载速度指示、外挂字体目录自动加载、音频设备切换 A/V 同步修复。所有菜单项按 Yaozhi 官方消息端点接线（`script-message-to`/`script-binding`），脚本零改动；升级后由应用自动同步到用户 MPV 目录（脚本全量覆盖、配置缺失补位）。
- **MPV 起播格式徽章升级为自绘图标**（对照 mpv-Yaozhi）：原来显示的是彩色文字胶囊（"Dolby Vision"/"HDR10+" 纯文字），现整体切换为 Yaozhi 同款自绘徽章位图资产（697 个文件随包捆绑，MIT 许可）——彩色品牌标与透明白图标两风格 × 1x/2x 两档源（1080p 1:1 渲染，1440p/4K 下采样保锐度不发糊）× 6 级预渲染透明度帧，起播淡入、停留、淡出动画完整；音频徽章同屏双布局，并补齐 DTS-HD MA/HRA 细分识别。渲染走 mpv 标准 `overlay-add` 原始位图通道（manifest 驱动布局），停靠角默认**右上**（`position` 可选四角，选左上时自动为信息条让位），仍锚定真实画面内容区；资产缺失或渲染失败自动回退原文字胶囊，旧配置键（style/时长/黑边识别）全部兼容。
- **Fntv-Plus 功能列表上线**（对照 mpv-Yaozhi 杳知功能菜单的可移植集）：右键 /「更多」菜单 → **Fntv-Plus** 子菜单，功能列表静态平铺、点开即列表（无二级入口）——超分与补帧、起播格式标签、音乐模式、置顶模式、视频章节显示（切章 OSD 标题）、起播自动全屏、最小化暂停播放（恢复自动续播，音乐模式激活时自动让路，对齐 Yaozhi 默认开启）、音频源码直通（AC3/DTS-HD/EAC3/TrueHD 常用集，设备不支持自动回落解码）。每次切换 OSD 提示状态；菜单项右侧实时显示当前状态（● 开启 / ○ 关闭，音乐模式显示具体循环档、置顶显示三态），由各脚本经 user-data 属性发布、uosc 菜单打开时动态刷新。
- **MPV「超分与补帧」自适应画质统一管理**（对照 mpv-Yaozhi 杳知）：设置面板新增统一卡片 —— 空间增强（超分）与时间平滑（补帧）两项独立开关、默认关闭、保存选择；自动档按显卡档位（Electron GPU 探测，五档：入门/均衡/中档/高档/旗舰）、片源分辨率、帧率、输出负载与画面格式选择方案。通用空间增强以 SSim（SSimSuperRes / SSimDownscaler）与 FSRCNNX 为主（随包新增 igv 着色器与 KrigBilateral 色度增强，均带许可文件），Anime4K、NNEDI3、RAVU 等保持手动选择且不会被自动替换；新增智能去色带（仅 8bit / 非 HDR / 低码率密度片源）。RIFE v4.6 预留 Vulkan / TensorRT FP16 双后端契约（随包内核未含 VapourSynth 运行时，配置扩展包后才建 AI 2× 链路，否则保持原生平滑）；RIFE 只在保持片源分辨率与超分质量时建链，绝不先降采样再补帧。HDR10 / HDR10+ 走保留 PQ、BT.2020 与逐帧信息的安全路径；HLG、杜比视界、原盘、VFR 与倍速场景自动保护，保持原始色彩链与原生平滑。暂停、跳转和播放恢复期间优先复用现有滤镜图（决策签名不变零属性写入），实时丢帧守卫连续过载只降不升（下一文件重新评估）。播放器内 右键 /「更多」菜单 →「超分与补帧…」可会话级实时切换（uosc 菜单带选中态）。
- **MPV 内核对齐 mpv-Yaozhi 1.0.6-2 生产栈**：蓝光 / DVD 原盘菜单与导航（HDMV 交互层、弹出层原子叠加、菜单音频恢复与队列、DTS-HD seek 重同步、导航头保留）、未激活内封字幕缓存（换轨秒切不重解）、蓝光远程镜像可拖动、wasapi / sdl 空间声布局保留、DV RPU 增强元数据、画面 / 字幕色彩空间控制；弹幕渲染全系列（铺满视口、按刷新率独立重绘、原子换轨、预算平滑）一并补齐。
- **MPV 专业起播格式标签**（对照 mpv-Yaozhi）：画面信息就绪后在真实画面安全区短暂显示画面 / 音频规格徽章 —— 画面标签 Dolby Vision / HDR Vivid / HDR10+ / HDR10 / HLG / SDR，音频标签 Dolby Atmos / DTS:X / TrueHD / DTS-HD / AC-4 / MPEG-H / Audio Vivid / DRA / APE / FLAC / PCM / AAC 等；音轨切换自动刷新，编码黑边识别后台完成（不阻塞首帧，徽章自动收进内容区），样式可选彩色徽章 / 透明白图标，与顶部信息条自动错位。HDR Vivid / HDR10+（scene-avg 可用性）均按真实元数据识别。

### 🔧 体验优化
- **音频响度档**：设置面板「播放」分类新增卡片 —— 觉得整体偏轻可选 **+3dB / +6dB 增益**，不同片源忽大忽小可选**响度归一化**（EBU R128，拉平到统一感知响度，自动回 48kHz 避免设备协商异常）；写入 mpv-user.conf 托管块，随下次播放生效，与「音频源码直通」互斥（直通时自动失效）。
- **修复自动超分不生效**：fntv_aq 读 `video-params` 原生表用了 `width/height` 键名（内核实际是 `w/h`），导致片源宽高恒为 0、放大倍率恒为 1，自动档永远不挂着色器链——实测插桩定位后修复，并实测自动档正确挂上 KrigBilateral → FSRCNNX → SSimDownscaler 完整链。
- **MPV 速度菜单自定义**：预设倍速列表改为可配置（uosc.conf 的 `speed_menu_items`，逗号分隔、自动去重升序），菜单末尾新增「自定义…」入口——打开播放器内置命令行并预填 `set speed`，输入任意倍速回车即生效；当前倍速不在预设内时该入口自动高亮。
- 弹幕轨道吞吐优化：碰撞判定按「会不会撞」释放轨道，高密度弹幕不再成堆被丢。
- MPV 弹幕菜单两级结构 + 原地刷新；空闲/换集瞬间不再因空播放地址报错。
- 应用图标迭代至 v10，安装器画稿进构建链；打包规则统一、构建占用自动重试（EBUSY）。
- 日志与诊断能力增强：轮播 / 弹幕 / Bangumi 全链路可在 app.log 取证，便于远程排查。
