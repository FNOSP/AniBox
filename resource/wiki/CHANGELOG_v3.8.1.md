# Fntv-Plus 更新日志

## v3.8.1 (2026-10-12)

> 本次更新聚焦**移动端 / 平板体验打磨**、**用户反馈卡顿的根因修复**与**随包 MPV 分发瘦身**：手机 / 平板专属布局与播放页底栏两行化、「UI 模式」手动切换、伪横屏全屏、弹幕排版与字号全面修正；透明窗口 30 帧上限根治、滚动动画风暴治理；应用内新增帧率诊断徽章（含 GPU 特征状态与慢帧归因）；安装器换新界面、进度条按真实体积走；MPV 依赖两轮瘦身（分发体积 -176MB），播放器空闲水印统一为 Fntv-Plus。

### 📱 移动端 / 平板
- **「UI 模式」手动切换**：首页新增「UI 模式」按钮（矢量图标，跟随「每日放送」显隐），手机版 / 电脑版一键切换并记忆，默认电脑版；不再依赖自动识别（自动判定在平板与触屏笔记本上容易给出错误布局）。新布局只在「触屏 + 短边 ≤ 820」的设备上启用，PC 样式一行未动。
- **播放页底栏两行化**：进度条带 + 按钮带两行布局，音量、倍速、弹幕、跳过、统计、更多等控件一屏可见，不再换行叠行、不再被挤出屏外；文字按钮字号统一 16px（与「选集」一致）；弹出面板定位与原生弹层收口。
- **手机 / 平板专属轮播（样式 5）**：触屏自动启用全宽单卡 + 原生横滑，存量样式 4 不再占位；竖版封面兜底、信息层重设计（用户真机反馈版）。
- **伪横屏全屏**：浏览器与飞牛 App 内不再与系统旋转打架（点击前判定 + 原生旋转失败自愈降级），被裁切样式补回；飞牛 App 内全屏后底栏不再挤出。
- **首页卡片对齐官方 App 尺度**（用户真机截图逐像素实测）：继续观看横版 16:9、卡片行重设计、手机模式顶栏收口（标题不再截断）、页面左留白 44→16、继续观看圆钮命中区收窄（误触修复）。
- **手机端基础四修**：轮播黑框、卡片过大、底栏挤出、全屏转横屏。

### ⚡ 性能（用户反馈卡顿的根因）
- **透明窗口 30 帧上限根治**：Windows 的 DirectComposition 合成路径会把透明窗口的持续更新钳制在 30Hz，本版关闭该呈现路径——实测非首页 54fps、静置回落 60fps；保留 `FNTV_KEEP_DCOMP=1` 环境变量便于对比排查。
- **滚动动画风暴治理**：列表滚动时虚拟列表每帧回收重建卡片会触发入场动画风暴，现在滚动期间（400ms 窗口）新出现的卡片与弹窗直接显示跳过入场动画；滚轮滚动不再反复全文档扫描样式（1.2s 最小间隔）。
- **播放按钮注入减负**：DOM 变更 200ms 防抖 + 空转轮询指数退避（1.2s → 封顶 10s，页面活跃自动回高频）；用 textContent 取代 innerText，免强制布局。
- **渲染日志批量合流**：preload 端 500ms 尾随批量（满 100 条 / error 立即冲刷），整批单次落盘，减少高频日志对主线程的打扰。

### 🩺 帧率诊断（新增，供自助排查）
- **FPS / 帧诊断徽章（`Ctrl+Shift+Alt+F`）**：实时帧率 + 慢帧归因（Long Animation Frames：>32ms 帧数、最贵脚本、样式重算、布局耗时）+ 慢帧滚动容器采样 + 透明窗实测形态显示（避免单实例 A/B 误测）。
- **GPU 特征状态**：主进程读取 Chromium GPU 状态（合成 / 光栅 / DRC / 2D / WebGL）随徽章显示，可一眼判断是否落到软件渲染。
- **玻璃滤镜一键开关（`Ctrl+Shift+Alt+B`）**：localStorage 持久化、首帧前注入，便于对比模糊特效的帧率开销。
- 诊断热键改为三键组合（原双键与常见软件冲突）。

### 🎬 弹幕
- **排版定稿**：回到轨道独占排版（顶部 / 底部 / 滚动不再共用轨道池），重叠错乱真因（渲染端 ×1.5 双重缩放）已删除；聚合弹幕放大后不再遮挡同轨。
- **密度与占比**：「弹幕密度」改为「展示占比」手动输入（只控同屏条数，显示范围不变）；另新增「自动缩放」开关——密集时按轨道占用率自动缩小字号。
- **字号自适应**：手机 / 平板上按**视频画面实际高度**计算（不再按画布全高，避免小屏过大）；4K / 高 DPI / 超宽屏补偿与描边随字号同比缩放沿用上一版。
- **菜单与记忆**：弹幕菜单改 hub-and-spoke 两级结构 + 原地刷新；「按类型屏蔽」并入弹幕样式子菜单；倍速按剧集持久化记忆（换集不再回到 1×）。
- **匹配与数据修复**：「第 5 集匹配到宣传视频」、「闪几秒就重来」的闭环振荡、自建源失败被缓存锁死 6 小时，三条根因修复；弹幕整条不显示的回退回归已修。
- **自建源多地址**：自建弹幕源支持多地址自动切换，失败根因直接展示在弹幕配置面板（不再只有一个「拉取失败」）。
- **网页弹幕**：fpk 端补齐「清除弹幕」（与桌面同语义）；调试日志新增一键复制按钮。

### 💿 随包 MPV
- **分发两轮瘦身**：依赖按「引用扫描 + PE 导入表 + 改名回放」三重验证逐一剔除未使用项（分发体积 -150MB）；再移除零引用的 Noto Serif CJK 字体（-26MB）。当前 Windows 安装包 **235.6 MiB**（解压 854 MiB），被移除的字体留有留档目录、可随时回滚。
- **空闲水印统一为 Fntv-Plus**：播放器空闲界面中央的品牌水印由上游 mpv-Yaozhi 改为 **Fntv-Plus**（沿用原双色版式），并清理界面里仍指向旧品牌（「杳知 / Yaoplayer」）的提示文案。
- 随包 MPV 的功能集（Fntv-Plus 功能列表、起播格式徽章、超分与补帧、内核对齐）见 v3.8.0 说明。

### 🖥 安装器
- **全新界面**：NSIS stub + WPF/WebView2 自绘四页（封面安装说明与发布日期、许可协议排版化、「安装包构建时间」、完成页对勾徽章）；卸载侧栏换成新稿。
- **进度与元数据**：进度分母按真实安装体积计算（此前会在中途就跑到 100%）；已安装检测加固（历史产品名 / 32 位视图 / InstallLocation 反推）。
- 真机问题修复：PLUGINSDIR 清理、GPU 抢占、双击入口路径不一致、协议弹层巡演。

### 🐛 其它修复
- 正式运行不再监听任何 TCP 端口（网关 socket 改读官方 ui/config）。
- 修复「有时候还是以前的样式」：网关地址被硬导航带跑、底栏布局样式改为无条件注入。
