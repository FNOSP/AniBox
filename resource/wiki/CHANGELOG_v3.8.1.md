# Fntv-Plus 更新日志

## v3.8.1 (2026-10-12)

> 本次更新**整体更换了随包 MPV**：内核对齐 mpv-Yaozhi 1.0.6-2 生产栈，并接入一整套 Fntv-Plus 功能集（24 项）、自绘起播格式徽章、超分与补帧自适应画质；同时修掉一批用户反馈的 bug：**卡顿**（透明窗口 30 帧上限、滚动动画风暴）、**弹幕**（错季匹配、闪几秒就重来、失败被缓存锁死、同轨堆叠错乱）、**播放页与移动端**（底栏换行叠行、轮播黑框、伪横屏被裁）等，详见下方修复清单。应用内另新增帧率诊断徽章（`Ctrl+Shift+Alt+F`）便于自助排查。

### 💿 全新 MPV（本版最大变化）

- **内核对齐 mpv-Yaozhi 1.0.6-2 生产栈**：蓝光 / DVD 原盘菜单与导航（HDMV 交互层、弹出层原子叠加、菜单音频恢复与队列、DTS-HD seek 重同步、导航头保留）、未激活内封字幕缓存（换轨秒切不重解）、蓝光远程镜像可拖动、wasapi / sdl 空间声布局保留、杜比视界 RPU 增强元数据、画面 / 字幕色彩空间控制；弹幕渲染全系列（铺满视口、按刷新率独立重绘、原子换轨、预算平滑）一并补齐。
- **Fntv-Plus 功能列表（24 项）**：右键 /「更多」→ **Fntv-Plus** 子菜单，静态平铺、点开即列表。新增 PGS 字幕亮度（自动识别 / 跟随视频峰值 / 150–400 nits 五档）、章节跳过（按章节名跳 OP/ED/广告 + F3 跳静音点）、按住右方向键平滑快进、动态去黑边、画中画、截屏（原样 / 框选裁剪 / 双图拼接）、导出当前字幕、快捷键绑定列表（uosc 内中文搜索与恢复）、最近播放、字幕自动对轴、字幕搜索下载（ASSRT）、字幕行列表跳转；另有九个自动生效项（属性跨会话记忆、跳转反馈动效、同目录自动连播、播放状态定时保存、音轨/字幕智能选择、跳转撤销重做、挂载盘速度指示、外挂字体目录、音频设备切换 A/V 同步修复）。菜单项右侧实时显示当前状态（● 开启 / ○ 关闭）。
- **专业起播格式标签（自绘徽章）**：原来只有文字胶囊，现在换为自绘徽章位图 —— 彩色品牌标与透明白图标两风格 × 1x/2x 两档源（1080p 1:1，1440p/4K 下采样保锐度）× 6 级预渲染透明度帧，起播淡入 / 停留 / 淡出完整；画面标 Dolby Vision / HDR Vivid / HDR10+ / HDR10 / HLG / SDR，音频标 Dolby Atmos / DTS:X / TrueHD / DTS-HD（含 MA/HRA 细分）/ AC-4 / MPEG-H / Audio Vivid / DRA / APE / FLAC / PCM / AAC 等，音轨切换自动刷新；默认停靠右上（可选四角，选左上自动为信息条让位），资产缺失或渲染失败自动回退文字胶囊。
- **「超分与补帧」自适应画质统一管理**：设置面板统一卡片，空间增强与时间平滑两项独立开关、默认关闭；自动档按显卡档位（Electron GPU 探测五档）、片源分辨率 / 帧率 / 输出负载 / 画面格式决策。空间增强以 SSim（SSimSuperRes / SSimDownscaler）与 FSRCNNX 为主（随包新增 igv 着色器与 KrigBilateral 色度增强），Anime4K / NNEDI3 / RAVU 保持手动选择不被自动替换；新增智能去色带（仅 8bit / 非 HDR / 低码率）。RIFE v4.6 预留 Vulkan / TensorRT FP16 双后端契约（未含 VapourSynth 运行时时保持原生平滑，绝不先降采样再补帧）；HDR10 / HDR10+ / HLG / 杜比视界 / 原盘 / VFR / 倍速场景自动保护；暂停、跳转、恢复期间复用滤镜图零属性写入，实时丢帧守卫连续过载只降不升。
- **播放器链路修复**：修复 MPV 播放**黑屏只有声音**（watch_later 残留弹幕滤镜导致滤镜链初始化失败，双保险根治）、全屏弹幕左右抖动与不显示（lavfi 滤镜按帧插值，挂链失败自动回退 OSD、硬解帧自动 hwdownload）；倍速改为**按剧集持久化记忆**（换集不再回到 1×）。

### 🐛 修复 · 卡顿与性能

- **透明窗口 30 帧上限根治**（用户反馈卡顿的根因）：Windows DirectComposition 合成路径会把透明窗口的持续更新钳制在 30Hz，本版关闭该呈现路径 —— 实测非首页 54fps、静置回落 60fps；保留 `FNTV_KEEP_DCOMP=1` 逃生开关便于对比。
- **滚动动画风暴治理**：虚拟列表滚动时每帧回收重建卡片会触发入场动画风暴，现在滚动期间（400ms 窗口）新出现的卡片与弹窗直接显示跳过入场动画；滚轮滚动不再反复全文档扫描样式（1.2s 最小间隔）。
- **播放按钮注入减负**：DOM 变更 200ms 防抖 + 空转轮询指数退避（1.2s → 封顶 10s，页面活跃自动回高频）；用 textContent 取代 innerText，免强制布局。
- **渲染日志批量合流**：preload 端 500ms 尾随批量（满 100 条 / error 立即冲刷），整批单次落盘，减少高频日志对主线程的打扰。

### 🐛 修复 · 弹幕

- **错季匹配根治**：第 5 集匹配到宣传视频 —— 候选原先只按弹幕条数取、从不校验是不是这一集，现在按「主名相等 + 季号一致」硬判，B站脏番名自动换词重试，低质条目不锁源缓存。
- **「闪几秒就重来」闭环振荡**：网页弹幕反复重新拉取的竞态修复。
- **自建源失败被缓存锁死 6 小时**：失败不再写长期缓存，下一集自动重试。
- **整条弹幕不显示**：上版回退带入的已删除函数调用修复。
- **同轨堆叠错乱（「往前一下又往后退」）**：排版定稿为轨道独占（顶部 / 底部 / 滚动不再共用轨道池），并删掉渲染端 ×1.5 双重缩放这一重叠真因；跨类型压字、聚合弹幕放大后遮挡、速率不一致三处一并修。
- **「只有十来条」**：轨道分配从「整批丢弃」改为按会不会撞释放轨道，重启后连续滚动。
- **弹幕密度与开关**：密度开关点击无反应（菜单派发白名单漏项）、密度回退不再整批丢弃；密度改为「展示占比」手动输入（只控同屏条数，显示范围不变）。
- **手机 / 平板弹幕字号**：改按**视频画面实际高度**计算（原先按画布全高，小屏过大）；新增「自动缩放」开关（密集时按轨道占用率缩字号）。
- **自建源多地址**：支持多地址自动切换，失败根因直接展示在弹幕配置面板。

### 🩺 新增：帧率诊断（自助排查）
