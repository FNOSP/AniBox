# AniBox 更新日志

## v4.4.0（2026-11-17）

> 弹幕改三源全拉；播放器新增「透明悬浮」皮肤并设为默认；IPTV 换自托管公共源并可自定义；短剧核心升级 guoapp v2（红果恢复、青空可登录）；发现页右栏与设置页整体整理。
