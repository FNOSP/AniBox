# AniBox 更新日志

## v4.5.0（2026-11-27）

> 新增「影院」详情页版式与首页「放映厅」轮播；播放器接入 RTX 视频增强、清晰度切换与进度条画面预览；弹幕新增腾讯/爱奇艺源与屏蔽词设置；修续播进度丢失、短剧连播与超时等一批问题。

### ✨ 新增功能

- 详情页新增「影院」版式：全屏封面 + Ken Burns 背景 + 玻璃控制台 + 横排选集卡（剧集与电影共用，默认仍为原版式，设置里可切换）
- 详情页新增「艺术图」选择器：海报 / 剧照 / Logo 可设为偏好，详情页与首页轮播同步使用
- 首页新增「放映厅」轮播样式：大图 + 作品 Logo + 标签行（年份 / 类型 / 状态 / 集数 / 评分），Logo 点击直达详情；原横滑样式保留，可切换
- 首页 / 发现页顶栏切换改为液态玻璃
- 播放器新增 RTX 视频增强：NVIDIA RTX 超分辨率（VSR）与 RTX Video HDR，由显卡驱动完成、零额外组件
- 播放器新增清晰度切换：底栏选档，原画直连、其余档走 NAS 转码；转码中换档原地生效不打断播放
- 播放器进度条悬停画面预览（缩略图），网络流可用
- 播放器音频弹窗新增「音画同步」±0.1 秒 / 清零
- 播放器「视频详情」新增 处理顺序 / 色彩 / 输出尺寸 / 输出帧率 / RTX 增强 行
- 弹幕新增腾讯视频、爱奇艺两个外部源（默认开启，设置可关）
- 短剧新增弹幕（随集缓存）、榜单入口（总热播 / 真人剧 / 漫剧 / AI剧榜）、倍速按剧记忆、分类分页加载（每页 50）
- 电影详情页新增「杂志」双栏版式并设为默认：艺术字标题、数据格、标签切换、层叠海报轮播；版本选择改信息卡（体积 / 编码 / 位深）并新增文件位置展示
- SVP 补帧按显示器刷新率自适应（最高 165Hz）；新增「伪 HDR」着色器档（SDR 提亮观感）
- 插帧长时间暂停后的恢复优化：先回填推理图再放行，避免恢复瞬间掉帧
- 演员头像无图时显示姓氏首字占位

### 🔧 修复

- 重装或重开软件后播放进度从 0 开始（服务端进度字段读错层级 + 续播点随安装目录被清空，现改存应用数据目录并自动迁移旧记录）
- 首页「继续观看」点播放键打开详情页而不是直接播放
- mpv 调了倍速，切下一集又被重置回 1 倍速
- mpv 窗口在任务栏 / Alt+Tab 显示 mpv 图标（已换为 AniBox logo）
- 短剧播完不自动连播、要点一下控制栏才继续（播放器管道读写在停帧时互相卡死）
- 短剧详情一直转圈到超时（全局锁把请求串行化）；详情弹窗关不掉、关掉又自己弹回
- 短剧分类栏只剩「全部」、切换标签显示暂无内容
- 透明悬浮皮肤下播放器弹窗文字在亮画面上看不清（改深色文字）
- 「视频详情」弹窗长内容超出卡片不换行
- 顶栏刷新按钮对演员数据无效（TMDB 缓存不强制回源）；部分演员头像空白（TMDB 上游数据变动，改用飞牛演员表兜底）
- 弹幕标题匹配误伤：集号后缀被长度惩罚拒掉、「第N集 + 副标题」从中间截断
- 图片偶发裂图（TMDB 镜像 502 自动重试一次）
- Bangumi 吐槽 / 评论在镜像故障时长时间白等（端点熔断 60 秒 + 报错文案面向用户）
- AI 增强组件下载后解压失败「program not found」（不再依赖 PowerShell，改进程内解压）；设置页显卡名称不显示
- 安装器在 2K 125% 缩放下第三张卡片被切、底部按钮消失
- macOS 15 起无法登录局域网 NAS（补本地网络权限声明与连接提示）
- 直播复用会话的预读参数被 mpv 拒绝导致预读失效
